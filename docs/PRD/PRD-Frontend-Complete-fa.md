# سند نیازمندی‌های فرانت‌اند سولو — کامل (فارسی)

## ۱. مرور کلی

سولو یک سامانه مدیریت دانش‌آموزان برای معلمان خصوصی و به ویژه کلاس‌های آنلاین است. این سند روی لایه فرانت‌اند تمرکز دارد: تجربه داشبورد React + TypeScript + Vite برای نقش‌های مدرس، زبان‌آموز، ولی و ادمین.

فرانت‌اند باید ساختاری مدرن، قابل توسعه، کاملاً RTL و مبتنی بر کامپوننت‌های قابل استفاده مجدد ارائه دهد و آماده یکپارچه‌سازی با لایه سرویس/بک‌اند باشد.

## ۲. چشم‌انداز

ارائه یک فضای دیجیتال یکپارچه که معلمان خصوصی بتوانند دانش‌آموزان، جلسات، حضور و غیاب، تکالیف و آزمون‌ها را مدیریت کنند و دانش‌آموزان و اولیا پیشرفت خود را به صورت روشن و فارسی مشاهده کنند.

## ۳. محدوده

### در محدوده

- معماری و ساختار پوشه فرانت‌اند
- احراز هویت نقش‌محور و محافظت روت‌ها
- UI داشبورد برای معلم، دانش‌آموز، ولی و ادمین
- پشتیبانی RTL و متن فارسی
- سرویس‌های داده نمایشی (mock)
- ساختار حرفه‌ای پروژه و مستندسازی

### خارج از محدوده

- کد بک‌اند NestJS
- ذخیره‌سازی واقعی دیتابیس
- پیام‌رسانی بلادرنگ واقعی
- بارگذاری فایل و پرداخت
- ماژول مدیریت موسسه/چندtenant

## ۴. نقش‌های کاربری

### مدرس

قابلیت‌های اصلی:

- مشاهده داشبورد شخصی کلاس
- مدیریت لیست دانش‌آموزان و برنامه جلسات
- ایجاد نمونه جلسه و آزمون
- بررسی حضور و تکالیف
- ارتباط با اولیا و دانش‌آموزان

### دانش‌آموز

قابلیت‌های اصلی:

- مشاهده پیشرفت فردی و تاریخچه جلسات
- دیدن جلسات آینده
- مرور تکالیف و امتیازات
- بازخورد معلم را دریافت کند

### ولی

قابلیت‌های اصلی:

- نظارت بر پیشرفت فرزند
- بررسی وضعیت حضور و تکالیف
- مشاهده گزارش آزمون‌ها
- دسترسی به داشبورد فرزند

### ادمین

قابلیت‌های اصلی:

- مشاهده معیارهای کلی سامانه
- بررسی KPIها و روندها
- مشاهده رتبه‌بندی دانش‌آموزان
- بررسی آمار استفاده و مشارکت

## ۵. نیازمندی‌های عملکردی

### احراز هویت و مسیرها

- صفحه ورود با نام کاربری و گذرواژه
- اعتبارسنجی mock با حساب‌های نمایشی
- ذخیره نشست در `sessionStorage`
- هدایت خودکار کاربران وارد شده به داشبورد
- محافظت نقش‌محور برای مسیرهای داشبورد
- جلوگیری از دسترسی نقش‌های غیرمجاز

### اسکلت داشبورد

- نوار کناری RTL و سربرگ بالا
- نشان نقش و عنوان صفحه
- رفتار پاسخگو و موبایل
- ظرف محتوای اصلی کارت‌محور

### مدیریت جلسات

- فهرست جلسات با فیلتر و نمایش نقش‌محور
- صفحه جزئیات جلسه با حضور، تکالیف و ارزیابی
- فرم ساخت جلسه برای معلم به عنوان تجربه UI
- نمایش تاریخ‌های فارسی و وضعیت حضور

### حضور و پیشرفت

- کارت‌های خلاصه حضور برای دانش‌آموز و ولی
- نمودار پیشرفت جلسات اخیر
- میانگین نمره و خلاصه عملکرد

### آزمون‌ها و تکالیف

- فهرست و جزئیات آزمون‌ها
- صفحه تکمیل آزمون توسط دانش‌آموز
- نمایش وضعیت نمره و نوع سوالات
- بخش‌های تکلیف و بازخورد در جزئیات جلسه

### پیام‌رسانی

- نمایش پیش‌نمایش گفتگو برای معلم و ولی
- لیست گفتگوهای ثابت با تاریخ فارسی
- مشاهده فقط خواندنی برای نسخه اولیه

### تحلیل‌های ادمین

- کارت‌های KPI برای حضور، تکالیف و کاربران
- نمودارهای روند پیشرفت ماهانه و حضور
- جدول رتبه‌بندی دانش‌آموزان

### UI/UX

- متن فارسی و پشتیبانی RTL
- لحن برند: مدرن، دوستانه، حرفه‌ای
- طراحی کارت‌محور با سایه‌های ملایم
- استایل فوکوس برای دسترسی
- سازگار با موبایل و دسکتاپ

### داده و سرویس mock

- داده‌های نمایشی در `src/mocks/`
- Helpers در `src/lib/`
- انواع در `src/types/`
- هوک `useMockData` برای انتشار داده نقش‌محور

## ۶. نیازمندی‌های غیرعملکردی

- React 19 + TypeScript + Vite
- Tailwind CSS v4 و توکن‌های تم
- مسیر `@/` برای ایمپورت‌های قابل توسعه
- ساخت تولیدی سریع و اسکریپت‌های آماده
- `README.md` حرفه‌ای برای راه‌اندازی
- HTML RTL و فونت فارسی
- ساختار پوشه قابل نگهداری و ایندکس‌های barrel
- پایداری کامل در ساخت

## ۷. معماری UI

### ساختار پوشه‌ها

- `src/app/` — پوسته برنامه، روت و providerها
- `src/components/layout/` — اسلکت و ناوبری
- `src/components/ui/` — کامپوننت‌های پایه UI
- `src/features/` — صفحات و ماژول‌های ویژگی
- `src/hooks/` — هوک‌های مشترک
- `src/lib/` — یوتیلیتی‌ها و کمک‌کننده‌ها
- `src/mocks/` — داده‌های نمایشی
- `src/types/` — تعریف انواع TypeScript

### مسیرها

- `/login` — صفحه ورود
- `/dashboard` — صفحه خانه نقش‌ها
- `/dashboard/sessions` — فهرست جلسات
- `/dashboard/sessions/:id` — جزئیات جلسه
- `/dashboard/attendance` — حضور و غیاب
- `/dashboard/messages` — پیام‌ها
- `/dashboard/students` — لیست دانش‌آموزان
- `/dashboard/admin/*` — تحلیل‌های ادمین

## ۸. معیارهای موفقیت

- مسیرهای نقش‌محور برای همه کاربران نمایشی کار می‌کند
- داشبورد نمایشی برای معلم، دانش‌آموز، ولی و ادمین نمایش داده می‌شود
- رابط RTL در موبایل و دسکتاپ صحیح رندر می‌شود
- ساخت با Vite و TypeScript موفقیت‌آمیز است
- اسناد در `docs/PRD/` موجود است
- ساختار فرانت‌اند واضح و قابل نگهداری است
