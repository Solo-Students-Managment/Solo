# PRD: Teachers (English)

## Overview

Teacher requirements: session creation, content upload, homework review, grading, and communication with parents/students.

## Features

- Create/edit sessions and materials
- Assign homework and review submissions
- Create exams and grade answers
- View class attendance and analytics
- Messaging with students and parents

## Acceptance criteria

- Teachers can create sessions and assign homework
- Grading flow allows recorded scores and feedback
