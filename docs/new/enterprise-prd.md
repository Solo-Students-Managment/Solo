# Enterprise PRD — SOLO

## 1. Objectives

### Business Goals

- Improve student evaluation accuracy
- Reduce teacher administrative workload
- Increase parent engagement
- Automate class and exam scheduling
- Enable scalable tutoring management system

---

## 2. KPIs

- Student performance score (0 - teacher-defined max)
- Monthly progress score (0–10)
- Session activity score (0–10)
- Teacher retention rate
- Paid subscription conversion rate

---

## 3. User Roles

### Teacher

- Manage students, classes, exams, assignments
- Track attendance and performance
- Communicate with students/parents
- Manage schedules and availability

### Student

- Attend classes and exams
- Submit assignments
- Track grades and progress
- Chat with teachers

### Parent

- Monitor student progress
- View schedule, exams, assignments
- Communicate with teacher
- Switch between multiple children

### Admin

- Full system control
- Manage users, roles, plans, payments
- Analytics and reporting
- Moderation and access control

---

## 4. Monetization Model

### Free Tier (14 days)

- Full access for teachers

### Basic Plan

- Monthly / 3 / 6 / 12 months

### Pro Plan

- Includes:
  - Teacher public profile page
  - File manager
  - Blog & SEO tools
  - Payment tools

---

## 5. Key Constraints

- Teacher must activate subscription after trial
- Data persists after downgrade
- Role-based feature unlocking
- Multi-student per teacher supported

---

## 6. Business Rules

- Exams must be pre-defined before execution
- Each question must have score weight
- Attendance required per session
- Anti-cheating mechanisms in exams
- Payment gating for Pro features
